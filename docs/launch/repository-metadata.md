## Repository Settings

- Default branch: `main`
- Issues: enabled
- Discussions: enable after there is capacity to moderate and answer questions
- Wiki: disabled unless documentation genuinely moves there
- Sponsorships: optional; do not block features behind sponsorship during v0.1
- Pages: GitHub Actions source
- Private vulnerability reporting: enabled
- Automatically delete head branches: enabled
- Squash merging: enabled; preserve meaningful commit messages
- Branch protection/ruleset: require the `quality` CI job before merging
