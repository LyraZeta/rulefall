# Roadmap

Rulefall's north star is a trustworthy, inspectable answer to: “Which repository instructions reach this coding agent, at this moment, and why?”

This roadmap is directional. Provider changes, maintainer capacity, evidence quality, and community feedback can change sequencing.

## v0.1: Waterfall

- Four-provider lifecycle comparison.
- Local folder and ZIP import.
- Startup, discovery, and edit phases.
- Explainable actions and confidence labels.
- PNG export and static GitHub Pages deployment.

## v0.2: Semantic Fixtures

- Versioned provider conformance fixtures.
- More complete path glob and frontmatter evaluation.
- Explicit precedence and override visualization.
- Machine-readable JSON trace export with a versioned schema.
- Permalink-safe redacted fixtures for bug reports.
- Provider documentation freshness indicators.

## v0.3: Conformance Lab

- Reproducible observation packs from real agent products.
- Documented-versus-observed comparison without claiming access to hidden prompts.
- Regression dashboards across provider releases and surfaces.
- Community-reviewed evidence and confidence changes.
- A CLI suitable for local automation and CI artifacts.

## Later Directions

- Additional coding agents and open instruction conventions.
- Custom provider profiles for internal tools.
- Migration suggestions that preserve semantics across providers.
- Privacy-preserving team baselines and trace comparison.
- Accessibility, localization, and large-monorepo performance work.

## Not Planned As Core

- Ranking instruction prose with an opaque AI score.
- Uploading private repositories to a hosted analysis backend.
- Pretending to reconstruct vendor system prompts.
- Automatically rewriting repository instructions without review.
- Growth mechanics that spam maintainers, communities, or unrelated repositories.

Vote on existing feature issues or open a focused request. A small reproducible repository fixture is more useful than a broad “support everything” request.
